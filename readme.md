Git команды:
cd - переход в каталог
git init - создание репозитория в выбранном каталоге
git status - информация о данном репозитории
git add "имя_файла" - добавление файла в репозиторий
git config user. - добавление данных о пользователе
git commit - создание коммита
git log - просмотр истории коммитов
git branch - создание ветки
git switch - переход на новую ветку (новая версия)
git checkout - переход на новую ветку (старая версия)
git merge - слияние веток
git branch -d - удаление ветки
git remote add origin - связывание удаленного репозитория с локальным
git push - отправка
git fetch - получение
git branch -r - показ список веток из удаленного репозитория
git pull - получение в локальную ветку файлы из удаленного репозитория
